From microphone to playback in 3 steps

  1. Measure the room from your chair

    Put a calibrated microphone where you listen and run the guided sweep. REW text exports and impulse WAVs load too.

  2. Automatic mode picks the correction

    Start with Automatic mode and the Mixed-phase filter. DecayCore shows which settings it chose and why.

  3. The correction loaded in your player

    Play a record you know and compare with bypass at the same volume. If it sounds worse, it is worse.

What do I need to measure the room?

A calibrated measurement microphone, a way to play the sweep, and a player that loads FIR convolution filters.

Which correction filter should I start with?

Automatic mode with the Mixed phase filter type, the default. It tries conservative settings first and shows which ones it chose.

Does the graph show my corrected room?

No. The predicted curve is the measurement with the filter applied in software. To measure the corrected room, route a sweep through your convolver.

What does DecayCore cost?

Nothing for non-commercial use. The packaged release adds guided measurement and Automatic mode to the manual Basic and Advanced modes.

Was DecayCore called CamillaFIR?

Yes. The name changed to avoid confusion with CamillaDSP, which DecayCore still exports for.
