# Mixed Phase Room Correction

DecayCore supports Mixed Phase FIR room correction.

Mixed phase correction can combine magnitude correction with controlled phase correction. The goal is not to blindly force perfect phase response, but to apply correction where it is useful and safe.

DecayCore uses practical correction limits to avoid excessive correction, pre-ringing, and unrealistic behavior.
